## 🔬 Laboratorio de infraestructura

Dispongo de un laboratorio virtualizado propio donde practico la instalación, configuración, administración y securización de sistemas informáticos.

Los proyectos incluyen documentación técnica, ejemplos de configuración y evidencias de las pruebas realizadas.

Mi metodología de trabajo se basa en:

1. Analizar los requisitos y el entorno.
2. Preparar y desplegar los servicios.
3. Aplicar medidas de seguridad y configuración.
4. Realizar pruebas funcionales y técnicas.
5. Identificar y resolver incidencias.
6. Documentar los resultados y las limitaciones.

## 🚀 Proyectos destacados

### 🔐 [Ubuntu Server Hardening Lab](https://github.com/erickconesa/ubuntu-server-hardening-lab)

**Linux | SSH | Hardening | Seguridad**

Administración y securización de un servidor Ubuntu Server en un entorno virtualizado.

- Autenticación SSH mediante claves Ed25519.
- Restricción del acceso remoto y de los privilegios.
- Configuración de servicios y actualizaciones de seguridad.
- Diagnóstico de incidencias relacionadas con SSH y cloud-init.
- Validación de configuraciones y evidencias técnicas.

### 🌐 [Nginx Reverse Proxy & Web Security Lab](https://github.com/erickconesa/nginx-reverse-proxy-security-lab)

**Nginx | HTTPS | Docker | Seguridad Web**

Configuración y validación de un proxy inverso Nginx con medidas de seguridad HTTP.

- Redirección HTTP a HTTPS.
- Configuración TLS y cabeceras de seguridad.
- Limitación de peticiones mediante rate limiting.
- Diagnóstico y resolución de incidencias.
- Scripts de comprobación y evidencias de validación.

### 🗄️ [PostgreSQL Administration, Security & Optimization Lab](https://github.com/erickconesa/postgresql-administration-security-optimization-lab)

**PostgreSQL 17 | Docker | SQL | Seguridad**

Administración y optimización de PostgreSQL en una infraestructura de laboratorio.

- Aislamiento del servicio mediante redes Docker privadas.
- Autenticación SCRAM-SHA-256 y restricciones con pg_hba.conf.
- Separación de roles y permisos DDL/DML.
- Ajuste de memoria y concurrencia.
- Análisis de consultas mediante EXPLAIN ANALYZE.
- Verificación de persistencia y disponibilidad.

### ⚡ [Redis & MongoDB Security and Performance Lab](https://github.com/erickconesa/redis-mongodb-security-performance-lab)

**Redis 7.4 | Percona Server for MongoDB 8.0 | Docker | NoSQL**

Implementación y administración de servicios de almacenamiento en memoria y bases de datos documentales.

- Configuración de caché Redis y políticas LRU.
- Gestión de sesiones y persistencia.
- Colas de trabajos asíncronos y recuperación de tareas.
- Pruebas comparativas de acceso a datos con PostgreSQL.
- Autenticación y control de permisos RBAC.
- Auditoría nativa de operaciones autorizadas y denegadas.

Los proyectos incluyen ejemplos saneados y documentación de laboratorio, sin publicar credenciales ni código de aplicaciones privadas.
